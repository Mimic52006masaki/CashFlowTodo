# アプリ要件定義

## 1. 目的・背景
- このアプリで解決したい課題：
  - 給与日を起点とした「家計に関する作業（振替・引き出し・支払い）」が複雑で、漏れやミスが起きやすい
  - どの口座にいくら残るかを事前に把握しづらい
- なぜ今このアプリが必要か：
  - 複数口座・現金・電子マネーを併用する家計が一般化しているため
  - 家計簿ではなく「実行管理」に特化したツールが不足しているため

## 2. ゴール
- このアプリが「成功」と判断できる状態：
  - 毎月の家計タスクを漏れなく処理できる
  - タスク完了と同時に残高が正しく更新され、ユーザーが安心して作業を進められる
  - 月次の家計作業時間が短縮される（主観評価でOK）

## 3. 想定ユーザー
- 主なユーザー：
  - 複数の銀行口座・現金・電子マネーを使い分けている個人
  - 家計管理を「作業」として整理したい人
- 利用シーン：
  - 給与日後の数日間に集中して使用
  - 月に1〜2回程度の利用

## 4. 機能一覧
### Must（必須）
- 月次セッション（給与日単位）の作成
- タスク（振替・引き出し・支払い等）の作成・編集・完了管理
- 口座・現金残高の管理
- タスク完了時の残高自動更新
- 月次テンプレートによるタスク自動生成

### Nice to Have（あれば良い）
- タスクの並び替え
- 月次履歴の参照
- CSVエクスポート
- 通知（※仮定：将来対応）

## 5. 対応プラットフォーム
- iOS（SwiftUI）
- ※仮定：初期リリースはiOSのみ、Web/Androidは対象外

## 6. 対象外（やらないこと）
- 銀行API連携
- 実際の送金・決済処理
- 家計簿的な支出分析・グラフ表示
