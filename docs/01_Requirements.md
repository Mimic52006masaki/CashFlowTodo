# アプリ要件定義

## 1. 目的・背景
- このアプリで解決したい課題：
  - 給料日に行う複数の口座間資金移動（振込・振替）が煩雑で、抜け漏れや金額ミスが起きやすい
  - 家計簿アプリでは「作業の実行管理」ができず、振込忘れを防げない

- なぜ今このアプリが必要か：
  - ネット銀行・複数口座の利用が一般化し、資金移動タスクが増えている
  - スマホで「その場で確認しながら実行できるチェックリスト」への需要が高まっている

## 2. ゴール
- このアプリが「成功」と判断できる状態：
  - ユーザーが毎月の資金移動タスクを漏れなく完了できる
  - チェック操作と同時に、振込後の残高イメージを把握できる
  - 翌月も同じアプリを自然に使い続けている

## 3. 想定ユーザー
- 主なユーザー：
  - 給料日に複数の銀行・口座を使って振込を行う個人ユーザー
- 利用シーン：
  - 給料日当日、スマホを見ながらネットバンキングで振込を行うタイミング

## 4. 機能一覧
### Must（必須）
- ユーザー認証（Googleログイン／匿名ログイン）
- 仮想口座の登録・編集・削除
- 振替ToDoの登録・編集・削除
- ToDoチェックに応じたリアルタイム残高シミュレーション
- データのクラウド保存（端末間同期）

### Nice to Have（あれば良い）
- 月次テンプレート（翌月用の一括リセット）
- 振込完了エビデンス（画像）添付（※将来）
- 給料日リマインド通知（※将来）

## 5. 対応プラットフォーム
- Web（PC / スマートフォンブラウザ）
- iOS / Android：Webアプリとして対応（ネイティブ対応は対象外）

## 6. 対象外（やらないこと）
- 実際の銀行口座・APIとの連携
- 家計簿・支出分析・グラフ機能
- チーム・家族での共有機能
