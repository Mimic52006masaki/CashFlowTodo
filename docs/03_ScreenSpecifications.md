# 画面仕様・画面遷移

## 画面一覧
1. ログイン画面
2. ホーム画面
3. 詳細画面（タスク編集）
4. 設定画面（口座管理）

## 各画面の仕様

### ログイン画面
- 入力項目：
  - なし（Googleログイン／ゲスト利用）
- 操作：
  - Googleログイン
  - ゲストとして利用開始

### ホーム画面
- 表示内容：
  - 今月の進捗バー（完了率）
  - 口座カード一覧（残高表示）
  - 振替ToDo一覧
- 操作：
  - タスクのチェック／解除
  - タスク並び替え（D&D）
  - 詳細画面へ遷移

### 詳細画面
- 表示内容：
  - From口座／To口座
  - 金額
  - メモ
- 操作：
  - 保存
  - 削除

### 設定画面
- 表示内容：
  - 口座一覧
- 操作：
  - 口座追加・編集・削除

## 画面遷移
- ログイン → ホーム
- ホーム → 詳細
- ホーム → 設定
