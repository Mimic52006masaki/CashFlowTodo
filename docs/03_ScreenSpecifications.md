# 画面仕様・画面遷移

## 画面一覧

1. 初回設定画面
2. ホーム画面
3. タスク詳細／編集画面
4. 月次設定画面
5. 口座管理画面

## 各画面の仕様

### 初回設定画面

- 入力項目：
  - 口座名
  - 初期残高
- 操作：
  - 初期データ保存 → ホーム画面へ遷移

### ホーム画面

- 表示内容：
  - 今月の予算
  - タスク一覧（チェックリスト）
  - 各口座の残高
  - ATM必要額
- 操作：
  - タスク完了チェック
  - タスク追加
  - 各設定画面へ遷移

### タスク詳細／編集画面

- 表示内容：
  - タスク種別
  - 金額
  - 出金元／入金先
  - メモ
- 操作：
  - 保存
  - 削除

### 月次設定画面

- 表示内容：
  - 給与日
  - 給与額
  - 今月の予算
- 操作：
  - テンプレート適用
  - 保存

### 口座管理画面

- 表示内容：
  - 口座一覧
  - 残高
- 操作：
  - 残高修正
  - 口座追加・編集

## 画面遷移

- 初回設定 → ホーム
- ホーム → タスク詳細
- ホーム → 月次設定
- ホーム → 口座管理
